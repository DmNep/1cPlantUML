# 1c PlantUML

Внешняя обработка 1С:Предприятие для схем обмена между информационными базами. Заполняете таблицы «Базы» и «Обмены» — получаете диаграмму PlantUML и картинку PNG.

Публикация на Infostart: [OBM SCHEM — формирование схемы обменов](https://infostart.ru/1c/2109404/).

Текущая версия задаётся комментарием метаданных обработки: **28-08-2026 v0.041**.

## Зачем это нужно

Схему обменов обычно рисуют вручную в PlantUML или Visio. Здесь тот же результат собирается из таблиц: удобно делегировать коллегам, быстро набросать карту контуров (УТ, БУ, ЗУП, КД 2.1) и сохранить её в файл.

Обработка универсальная и не привязана к конкретной конфигурации.

## Возможности

- Таблицы **Базы** и **Обмены**: источник, приёмник, наименование, двусторонний обмен.
- Комментарии к базам и обменам, в том числе справа от стрелки. Несколько строк — через `|`.
- Иконки баз: база, человек, коллекция.
- Разделители на схеме: строка обмена без баз становится заголовком секции.
- Оформление линий: цвет, толщина, пунктир (в полном интерфейсе).
- Заголовок схемы, упрощённый и полный режим формы.
- Рендер через HTTPS API [PlantUML](https://www.plantuml.com) (`www.plantuml.com/plantuml/png/`). При необходимости сервер и ресурс можно сменить в полном интерфейсе.
- Сохранение и загрузка настроек в XML.
- Загрузка списка обменов из табличного документа MXL.
- Выгрузка текста `.puml` и картинки `.png`.
- Регистрация как дополнительная обработка БСП. Безопасный режим выключен: нужен HTTP и работа с файлами.

Диалоги файлов асинхронные и работают в тонком клиенте, где синхронный `Диалог.Выбрать()` запрещён.

## Требования

- Платформа **8.3** (сборка проверялась на 8.3.27).
- Управляемое приложение, тонкий или толстый клиент.
- Доступ в интернет к серверу рендеринга, либо свой PlantUML-сервер.
- Для регистрации в справочнике дополнительных обработок — БСП.

## Как пользоваться

1. Откройте `build/1c PlantUML.epf` или загрузите обработку из XML-выгрузки.
2. Заполните таблицу **Базы**. Они появятся в списках источника и приёмника.
3. Заполните **Обмены** и при необходимости заголовок схемы.
4. Нажмите **Сформировать схему**.
5. Сохраните настройки (XML), текст PlantUML или PNG.

Загрузка из MXL рассчитана на колонки вроде «Наименование», «Источник», «Приёмник» — так можно выгрузить конвертации из Конвертации данных 2.1 и быстро получить черновик схемы.

## Сборка

Исходники — Designer XML 2.20. Собрать EPF можно Конфигуратором:

```text
1cv8 DESIGNER /F "<информационная база>" /LoadExternalDataProcessorOrReportFromFiles 1c_ObmSchem.xml "1c PlantUML.epf"
```

Локальную строку соединения и путь к платформе кладите в `v8project.local.yaml`, этот файл в git не входит.

Автотест формы запускается так:

```text
1cv8 ENTERPRISE /F "<информационная база>" /Execute "1c PlantUML.epf" /C Автотест
```

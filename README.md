# 1c PlantUML

Внешняя обработка 1С:Предприятие для наглядной схемы обменов между информационными базами. Заполняете таблицы «Базы» и «Обмены» — получаете диаграмму PlantUML и картинку PNG.

Публикация на Infostart: [OBM SCHEM — формирование схемы обменов](https://infostart.ru/1c/2109404/) (№ 2109404, автор Дмитрий Непобедимый).

## Зачем это нужно

Обработка формирует схему обменов между базами в системе. Она пригодится и начинающим, и опытным разработчикам: для обучения, быстрого анализа и как напоминалка по контурам (УТ, БП, ЗУП, ЕРП и др.). Универсальная, подходит для любой конфигурации, как отдельный EPF **не требует БСП**.

Визуальная схема помогает планировать обмены, находить узкие места в проектировании и документировать историю изменений структуры обменов.

Идея возникла из практики: схемы постоянно рисовались в PlantUML, а когда работу нужно было делегировать коллегам, оказалось проще написать обработку, чем обучать синтаксису PlantUML. Рабочие схемы можно получить за несколько минут.

## Возможности

- Таблицы **Базы** и **Обмены**: источник, приёмник, наименование, двусторонний обмен. Строки в табличную часть добавляются после текущей.
- После заполнения «Базы» они становятся доступны в «Обменах» как источник и приёмник. Пустые строки баз в выбор не попадают; перед формированием схемы пустые строки табличных частей удаляются.
- Комментарии к базам и обменам, в том числе справа от стрелки и слева от базы. Несколько строк — через `|` (вертикальная черта, Alt+124 на цифровой клавиатуре).
- Иконки баз: база (по умолчанию), человек, коллекция.
- Разделители на схеме: строка обмена без баз становится заголовком секции.
- Оформление линий: цвет, толщина, пунктир (в полном интерфейсе).
- Заголовок схемы; переключение упрощённого и полного режима формы.
- Рендер через HTTPS API [PlantUML](https://www.plantuml.com) (`www.plantuml.com/plantuml/png/`). Можно указать свой сервер и ресурс в полном интерфейсе.
- Сохранение и загрузка настроек в XML. Файлы предыдущих версий OBM SCHEM загружаются.
- Загрузка списка обменов из табличного документа MXL (колонки «Наименование», «Источник», «Приёмник») — например, список конвертаций из Конвертации данных 2.1.
- Выгрузка текста `.puml` и картинки `.png`.
- По желанию — регистрация как дополнительная обработка БСП. Безопасный режим выключен: нужен HTTP и запись во временный файл при подготовке данных для API PlantUML.

Диалоги файлов асинхронные и работают в тонком клиенте, где синхронный `Диалог.Выбрать()` запрещён.

## Требования

- Платформа **1С:Предприятие 8.3**. Сборка и автотест в этом репозитории — на 8.3.27.
- Управляемое приложение, тонкий или толстый клиент.
- Доступ в интернет к серверу рендеринга либо свой сервер PlantUML.
- БСП нужна только если регистрируете обработку в справочнике дополнительных обработок.

## Как пользоваться

1. Откройте собранный `build/1c PlantUML.epf` или загрузите обработку из XML-выгрузки.
2. Заполните таблицу **Базы**. Они появятся в списках источника и приёмника.
3. Заполните **Обмены** и при необходимости заголовок схемы.
4. Нажмите **Сформировать схему**.
5. Сохраните настройки (XML), текст PlantUML или PNG.

Загрузка из MXL рассчитана на колонки «Наименование», «Источник», «Приёмник».

## Сборка

Исходники — Designer XML 2.20. Собрать EPF можно Конфигуратором:

```text
1cv8 DESIGNER /F "<информационная база>" /LoadExternalDataProcessorOrReportFromFiles 1c_ObmSchem.xml "1c PlantUML.epf"
```

Локальную строку соединения и путь к платформе кладите в `v8project.local.yaml`, этот файл в git не входит.

Автотест формы запускается так:

```text
1cv8 ENTERPRISE /F "<информационная база>" /Execute "1c PlantUML.epf" /C Автотест
```
